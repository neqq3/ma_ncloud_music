# 0.4.0 Forward Unto Dawn

## 兼容性与架构更新

- **Music Assistant 新版兼容**：适配 Music Assistant 2.10 的新版 Provider 配置与 Setup Flow，同时保留旧版 Provider 配置流程。
- **统一版本支持**：同一份 NCloud Music Provider 设计支持 **Music Assistant 2.7.x 至当前最新版本（目前为 2.10.x）**，无需针对 2.9 / 2.10 分别维护不同插件版本。
- **平滑升级**：保留原有登录凭据、音质、封面尺寸等配置读取逻辑，升级 Music Assistant 后可继续沿用现有 Provider 配置。
- **向后兼容**：旧版 Music Assistant 继续使用原有配置入口；如有更早版本的兼容需求，欢迎提交 Issue。

## 其他调整

- **结构整理**：将旧版 Provider 主逻辑保留在 `legacy_impl.py`，新增统一兼容入口与 MA 2.10 `setup_flow.py`。
- **文档更新**：README 更新 Music Assistant 兼容范围与安装说明。
